# PLAY HUMAN UX PRINCIPLES v1.0
## Product Experience Foundation / AG Reference Standard

**Status: FIXED**  
**Scope: All future PLAY Human Product / UX work**  
**Owner: Product Owner**

## 1. Core UX Objective

PLAY must create a continuous chain of curiosity:

`DISCOVER → CURIOSITY → EXPLORE → JUDGE → ACT → RESULT → ACHIEVEMENT → NEW CURIOSITY → DISCOVER AGAIN`

The fundamental UX question is:

> Does this create a reason for the user to discover the next value, information, or choice?

## 2. Fixed Product Decisions

### Q1. First 30 seconds: **A + C + D**
- **A. My Starting Resources:** the user immediately understands that they have 700M KRW and therefore meaningful ability to act.
- **C. Other Participants:** the user understands that others started under comparable conditions.
- **D. Moving Economic World:** the user understands that the economic environment is changing.

Conceptual sequence:

`MY RESOURCES → OTHER PEOPLE → ECONOMIC WORLD → “WHAT SHOULD I DO?”`

### Q2. Exploration Driver: **E 중심 + A/B/C/D**
The primary driver is: **there is always something I have not discovered yet.**
Supporting discovery sources are the user's assets/state, interests, other participants, and economic/environmental changes.

### Q3. Discovery → Action: **C → D → E**
`CHANGE → WHY? → CAUSE/CONTEXT → NEW POSSIBILITY → OTHER PEOPLE → MY DECISION`

The system should not prescribe the “correct” action.

### Q4. Action → Re-engagement: **A + B + C + D + E**
- **A:** immediate result
- **B:** expected vs actual
- **C:** difference from others
- **D:** new possibility
- **E:** Push re-engagement

### Q5. Final Value: **E + C + D + A**
- **E:** discover new possibilities
- **C:** discover one's own decision pattern
- **D:** observe/compare with others
- **A:** economic achievement through operating money/assets

Economic achievement is not defined only by maximum wealth. It can include asset growth, cash-flow stability, debt management, economic freedom, consistency, decision quality relative to expectations, strategy discovery, and long-term outcome.

## 3. Push Notification Principle

Push is part of the product loop, not advertising.

Required conceptual categories:
1. **My Result** — consequences of the user's own actions.
2. **My Interest** — changes in explicitly watched regions/properties/markets.
3. **World Flow** — important economic/environmental changes.
4. **Other Participants / Season** — meaningful participant or Season-level changes.

At minimum users must control:
- All notifications ON/OFF
- My Result ON/OFF
- My Interest ON/OFF
- World Flow ON/OFF
- Other Participants / Season ON/OFF

Where appropriate, frequency can include Immediate / Daily Summary / Important Changes Only / OFF.

The desired loop is:

`RELEVANT CHANGE → PUSH → “WHAT HAPPENED?” → PLAY RETURN → DISCOVERY`

## 4. Master UX Loop

`ECONOMIC WORLD → DISCOVERY → CURIOSITY → EXPLORATION → JUDGMENT → ACTION → RESULT → ACHIEVEMENT / COMPARISON / SELF-DISCOVERY → NEW POSSIBILITY → NEW CURIOSITY → DISCOVERY`

## 5. Seven Non-Negotiable Principles

1. **Immediate Value** — quickly understand what I have and can do.
2. **Continuous Discovery** — meaningful experiences should leave a reason for the next discovery.
3. **Self-Driven Decision** — information and consequences, not a prescribed correct answer.
4. **Action Creates Consequence** — meaningful actions produce understandable consequences.
5. **Living World** — the world continues changing when the user is inactive.
6. **Persistent Curiosity** — relevant changes can bring the user back after leaving.
7. **Achievement Through Operation** — achievement comes from operating in the economic world and experiencing consequences.

## 6. UX Evaluation Gate

Every future UX proposal must answer:

- G1. Does the user know what they have?
- G2. Is there a reason to explore?
- G3. Can the user discover something new?
- G4. Does discovery create a meaningful choice?
- G5. Does the choice create a visible consequence?
- G6. Does the consequence create a new question?
- G7. Can the user discover how others behaved?
- G8. Can the user feel achievement through economic operation?
- G9. Can the world create a reason to return after leaving?
- G10. Can the user control notifications?

Conflicts require Product Owner review before implementation.

## 7. Anti-Patterns

- Static dashboard with no discovery loop
- Prescriptive “correct choice” UX
- Artificial quest spam
- Notification spam
- Pure wealth ranking
- Dead world that only changes when the user acts
- Action without consequence
- Consequence without explanation

## 8. Research Logging Alignment

UX should naturally support:

`EXPOSURE → DECISION → ACTION → VALIDATION → TRANSACTION / OUTCOME`

Human experience comes first; measurement must remain unobtrusive.

## 9. Change Control
